They are preserved because they demonstrate why the original subjective review was retracted. The previews are nearest-neighbor downscaled/palette-reduced to keep Git history small; `artifact-manifest.json` records SHA-256 hashes and byte sizes for both each committed preview and its original supplied source image.

Visible failure modes include models absent from labeled tiles, severe/near-plane polygon artifacts around opening assets, environment-dominated floor/wall captures, repeated `MISSING` cards, and a contextual background whose obsolete `dungeon_default` texture overwhelms model diagnosis.

Root-cause analysis and the corrective protocol are documented in `../../in-engine-review.md`.
